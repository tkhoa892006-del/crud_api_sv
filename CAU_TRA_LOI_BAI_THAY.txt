2. API CRUD BANG STUDENTS
--------------------------

Controller chinh:
File: src/main/java/com/example/spring_api/StudentController.java
Duong dan:
C:\TaiLieu\hoc_java\crud_api_sv\basic-api-student-sql-server\src\main\java\com\example\spring_api\StudentController.java

Base URL:
http://localhost:8080/api/students

2.1. API them sinh vien

Method va URL:
POST /api/students

Annotation:
@PostMapping

Doan code doi chieu:
StudentController.java, dong 40-45.

Du lieu JSON mau:
{
  "studentCode": "SV0011",
  "fullName": "Nguyen Van B",
  "email": "b@example.com",
  "phone": "0900000011",
  "className": "C2024A"
}

Lenh PowerShell mau:
Invoke-RestMethod -Method Post `
  -Uri "http://localhost:8080/api/students" `
  -ContentType "application/json" `
  -Body '{"studentCode":"SV0011","fullName":"Nguyen Van B","email":"b@example.com","phone":"0900000011","className":"C2024A"}'

2.2. API xoa sinh vien

Method va URL:
DELETE /api/students/{id}

Annotation:
@DeleteMapping("/{id}")

Doan code doi chieu:
StudentController.java, dong 58-66.

Luu y:
{id} la UUID cua sinh vien. API tra ve HTTP 204 neu xoa thanh cong va HTTP 404
neu khong tim thay sinh vien.

Lenh PowerShell mau:
Invoke-RestMethod -Method Delete `
  -Uri "http://localhost:8080/api/students/{id}"

2.3. API cap nhat sinh vien

Annotation:

Doan code doi chieu:

Lenh PowerShell mau:

  -Uri "http://localhost:8080/api/students/{id}" `

4. QUY TRINH CODE API CRUD KET NOI VOI BANG DU LIEU
----------------------------------------------------

Quy trinh xu ly:

Buoc 1 - Client gui HTTP request:
Trinh duyet, Postman, Swagger hoac PowerShell gui request den
/api/students.

Buoc 2 - Controller tiep nhan request:
StudentController nhan method HTTP, path variable, query parameter va request body.

Buoc 3 - Service xu ly nghiep vu:
StudentService goi ham tim, them, cap nhat hoac xoa. Service cung xu ly truong hop
khong tim thay sinh vien.

Buoc 4 - Repository truy cap database:
StudentRepository ke thua JpaRepository<Student, UUID>. Spring Data JPA tu dong
tao cac cau lenh SQL can thiet de lam viec voi bang students.

Buoc 5 - Entity anh xa du lieu:
Student.java anh xa class Student voi bang dbo.students trong database student_db.

Buoc 6 - Database tra ket qua:
SQL Server thuc hien SELECT, INSERT, UPDATE hoac DELETE va tra du lieu ve.

Buoc 7 - Tra response:
Controller tra JSON ve cho client. Website dung ket qua de hien thi lai danh sach.

So do:
Client -> Controller -> Service -> Repository -> SQL Server
SQL Server -> Repository -> Service -> Controller -> Client

Cac file doi chieu:
- Controller: src/main/java/com/example/spring_api/StudentController.java
- Service: src/main/java/com/example/spring_api/StudentService.java
- Repository: src/main/java/com/example/spring_api/StudentRepository.java
- Entity: src/main/java/com/example/spring_api/Student.java
- Website controller: src/main/java/com/example/spring_api/StudentPageController.java
- Website HTML/JavaScript: src/main/resources/templates/students.html
- SQL database: database/data.sql
